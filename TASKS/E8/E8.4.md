## Description

Users must always know what is AI and what is not, and must be able to say when it is wrong (FR6.3).

## Work needed

- An 'AI-generated' label on every AI output: search filters, match reasons, contract summary.
- The contract result states that it is not legal advice.
- A button to report a wrong result, writing a `reports` document, with a note of which feature produced it.
- One shared label component for AI output, used by search chips, match reasons and the contract result.
- Report a wrong result: choose the feature, add a note, send; the student sees a confirmation.
- A short help text explaining what the label means.
