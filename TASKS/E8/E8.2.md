## Description

A tenancy agreement is where students lose money and cannot read the clauses. Marking each clause Red flag, Check or OK with a plain-language summary is a job rules cannot do, so it is the second allowed use of AI. The result is private and says it is not legal advice.

Proposed function `checkContract` returns a summary and clauses with `aiGenerated: true` and `notLegalAdvice: true`; the schema stores the result as `contractChecks` (summary, flags with level `red_flag`/`check`/`ok`, clause, text).

## Work needed

- Collect 10 anonymised sample agreements and write down by hand the risky clauses of each (the reference answers).
- Worker function that accepts an uploader-owned file only (never an arbitrary URL), extracts the clauses and marks each one.
- Prompt and fallback behaviour when the AI fails (show a message, never a made-up result).
- Count flags found and false alarms against the reference answers for E8.5.
