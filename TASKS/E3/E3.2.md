## Description

Students filter by budget, room type, area, gender preference, amenities and maximum travel time to their faculty. Filters combine with AND. The same filter object must be produced by the manual sheet and by the AI search (E3.5), so the AI result can be shown, edited and run.

## Work needed

- Filters sheet: budget range (sen), room type, area (`areas`), gender preference (`genderPref`), amenities.
- Travel-time filter: calls the commute function (E3.3) for the student's faculty and class start time and keeps rooms within the limit.
- A single `RoomFilter` model used by the sheet, the query and the AI search.
- Clear and reset; a visible count of active filters.
