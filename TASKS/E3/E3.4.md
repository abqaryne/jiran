## Description

The number a student compares is the true monthly cost: the room price plus an equal share of utilities plus the commute cost of the cheapest travel mode that still arrives on time at their real departure time. If no mode arrives on time, the card says so instead of showing a cost.

## Work needed

- Compute `trueMonthlyCostSen = roomPriceSen + utilitiesShareSen + monthlyCommuteSen` with the response fields of `getCommuteOptions` (`selectedMode`, `trueMonthlyCostSen`, `roomPriceSen`, `utilitiesShareSen`, `isEstimate`).
- Room card shows the cost and the travel time; the 'no mode reaches class on time' state replaces the cost.
- Cache results for the same area and faculty pair in Firestore (no user identity, no private schedule) to protect NFR1 and the free-plan quotas.
- Detail page names the mode used for the figure.
