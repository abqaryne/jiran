## Description

Searching vacant rooms is the first thing a student does. The result is one Room card per vacant room (`RoomCardView`, E0.3), because the true monthly cost depends on that room's price. A card shows price, true monthly cost and travel time to the student's faculty; CO₂ appears only on the detail page.

## Work needed

- Query `rooms` with `status == 'vacant'` joined to their active `listings` (building, area, photos); sort by true monthly cost.
- Rooms screen with a search bar, the filter entry point and Room cards; an empty state when nothing matches.
- Saved rooms: a student can save and unsave a room and see the list.
- Use the sample listings from E2.4 until real ones exist.
