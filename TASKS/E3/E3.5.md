## Description

A student can type a request such as 'quiet room near UM under RM550' in English or Malay and the AI turns it into search filters. This is one of the three places where AI is allowed because rules cannot read free text. The filters are always shown for editing before results load, so a wrong reading cannot hide results silently.

## Work needed

- Worker function `parseSearchRequest` (`text`, `language`) returning `filters`, `requiresConfirmation: true`, `aiGenerated: true`.
- Rooms search bar: editable chips for each parsed filter; the search runs only after the student confirms.
- Manual filters work when the AI is down.
- A set of 50 test requests written by surveyed students, with the expected filters, for the evaluation in E8.5.
