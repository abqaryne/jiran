## Description

The score must be transparent and testable, so code computes it and the AI never does. Aaron merged `rankMatches` in `backend/functions/src/match.js`: seven factors with explicit versioned weights in basis points (sum 10000), per-factor similarity in basis points, a weighted overall score, deterministic ordering, `insufficient_data` when a positive-weight answer is missing, and the overlapping class days.

## Work needed

- Similarity rules: sleep = 1 − shortest cyclic difference / 720; cleanliness, noise, cooking = 1 − |difference| / 4; smoking and pets = agreement; budget = interval intersection / union.
- Half-up integer rounding in basis points; `score = scoreBasisPoints / 100`.
- Sort by descending score then candidate ID; at most 100 candidates; reject duplicate IDs.
- Return the factor breakdown and rule reason codes (`similar` ≥ 7500, `different` ≤ 2500, otherwise `partial_overlap`).
- Replace the placeholder weights with the survey-based ones (assumption #9).
