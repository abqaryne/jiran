## Description

The ranked list is how a student finds a housemate; the profile page is where they decide to connect. At the Match stage only initials, faculty, year, lifestyle tags, score and reasons and overlapping class days are visible; name, photo, phone, address and timetable details are not.

## Work needed

- Match results screen: ranked cards with initials, faculty, year, tags, score, short reasons and class-day overlap.
- A candidate without a score shows 'not enough data', not zero.
- Match profile page with only Match-stage fields.
- Connect: sends a request using the same flow as E5.1; sets `statusA`/`statusB` on `matches/{uidA_uidB}`.
- Use fake scores until E6.2 is wired.
