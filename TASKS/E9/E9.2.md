## Description

A group of two to eight rents a whole unit together; its creator sets the maximum. The app puts the same facts in front of everyone and never decides for the group. Data: `groups` (memberUids, maxMembers, createdByUid, name, inviteCode, inviteExpiresAt, joinRequests, targetListingId/targetEvalId, roomSplit, splitOption, memberStatus, checklist, acceptedBy, status forming/confirmed/dissolved).

## Work needed

- `groups` data and rules. A student is in one Group at a time (Rules and the app both check it); the entries "Form a group" become "Open group" once a Group exists, and the Housemates tab shows the "Your group" card (E6.4).
- Entries (Ary, 12 Nov 2026): **Create a group** and **Join with a code** in the Housemates tab (E6.4), the "Form a group" row in the + menu of a Connection chat (E5.2, opens Create a group with that Connection already invited) and the "Rent a Unit together" card in the Unit tab of a student with no Household (E7.3); no prompt card in the thread. There is no button on Match results.
- Create a group: a name (optional) and the maximum number of members, 2 to 8 (prefilled with 4); the maximum can be changed later but never below the current number of members.
- Invite to the group: a 6-character code valid 7 days (the creator can make a new one) and a link that carries the same code, or pick a Connection. A student who enters the code or opens the link sends a join request; the creator accepts or declines it in the Group screen. A full Group refuses requests. Joining opens no contact details: members see the Match-stage profile and become Connections only through the normal request.
- A Group of one is dissolved when its code expires unused.
- Split options in one tap: equal, by room type (default weights), custom; every option adds up exactly to the Unit rent.
- Member status: In, Not sure or Needs changes with a short note; the group is confirmed only when everyone is In.
- Pre-signing checklist (contract checked, deposit discussed, signer chosen): a reminder, not a gate.
- Changing any price resets every acceptance; a member leaving resets them and a Group left with fewer than two members dissolves.
- Choose the Host when several sign together.

## Constraints

- Groups hold two to eight members; the creator sets the maximum (never below the current members). A student is in one Group at a time.
- On confirmation the Group becomes the Household with the same members and prices (E5.3, E7.2).
- The group picks one member as Host; by default the person who created the group, and any member can hand it over before signing.

## Acceptance (how QA checks it)

Aly runs these checks and records the result in ClickUp.

- [ ] Split options (equal, by room type, custom) each add up exactly to the rent.
- [ ] Each member marks In, Not sure or Needs changes with a note; the group is confirmed only when everyone is In.
- [ ] A pre-signing checklist is a reminder, not a gate.
- [ ] If a member leaves, every acceptance resets and a Group left with fewer than two members dissolves.
- [ ] A student can create a Group from the Housemates tab and choose a maximum from 2 to 8; the maximum cannot go below the current number of members.
- [ ] A second student who enters the code (or opens the link) sends a join request; the creator accepts or declines; an expired code and a full Group are refused; a student already in a Group cannot join another.
- [ ] Joining a Group does not show anyone's phone or exact address.
