## Description

Jiran's commute, match and AI features need server code, but the team's budget is free only (decision of 27 Oct 2026). Firebase Auth and Firestore stay on the Spark plan; the server is a Cloudflare Worker on the free plan, routing is openrouteservice plus Prasarana GTFS timetables, and the map is MapLibre. Cloud Functions, Firebase Storage and Google Routes are not activated.

This story proves the free stack is enough before feature stories depend on it. Aaron's evidence is in `docs/research/maps-readiness.md`, `docs/research/free-transit-evidence.md`, `docs/research/no-billing-production.md` and `docs/engineering/architecture.md`.
