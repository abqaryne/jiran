## Description

Before contacting a Host a student needs the whole picture of one room. The detail page shows photos, the room price, the separate one-way commute estimate with the mode used, the Host's initials, and the other rooms of the same Unit with their status. The exact address stays hidden until a Connection exists (stage table, PRD section 5).

## Work needed

- Room details screen from `rooms/{roomId}` and `listings/{listingId}` (photos, building name, area, amenities, gender preference, deposit).
- Separate one-way commute estimate block with the mode used (from E3.4) and an estimate label.
- Rooms in the unit: type, price, vacant or occupied. A vacant Room that is not the one being viewed has a chevron and opens its own Room details; an occupied Room has none. The Room being viewed is marked (tinted row, "Vacant · viewing now") so the student knows which row is theirs (Ary, 11 Nov 2026; Figma frame "Room details").
- Host block: initials only (stage Match/Request), never name, photo or phone.
- Share and save (saved rooms list from E3.1).
- Report listing sheet: reason plus optional note, writes a `reports` document (targetType `listing`).

## Constraints

- Room headline price and the same Room in the Unit list must read the same stored Room price; the supplied screenshot is a mock layout, not seed values.

- Ary, 11 Nov 2026: monthly Room rent stays separate from per-trip time/fare; true monthly cost is removed. No timetable or campus-day input. See [PRD Module 4](../../docs/product/PRD.md#module-4-apartment-to-faculty-commute-guide) and [file handoff](../../docs/plans/2026-11-11-commute-per-trip.md).

- The exact address and `residentUids` live in `listings/{id}/private/location` and are readable only by the Host, residents and a student whose request the Host accepted.
- The contract check never appears on a listing page (PRD Module 6).
- Commute card (E4.2) and request sheet (E4.3) are separate stories placed on this page.
- Reported listings: reports go to a `reports` collection; Gathan moderates, Ary is the backup; the sheet says only "The team will review this" and promises no time; the item stays visible until a moderator hides it.
