## Description

Before contacting a Host a student needs the whole picture of one room. The detail page shows photos, the room price, the true monthly cost with the mode used, the Host's initials, and the other rooms of the same Unit with their status. The exact address stays hidden until a Connection exists (stage table, PRD section 5).

## Work needed

- Room details screen from `rooms/{roomId}` and `listings/{listingId}` (photos, building name, area, amenities, gender preference, deposit).
- True monthly cost block with the mode used (from E3.4) and an estimate label.
- Rooms in the unit: type, price, vacant or occupied.
- Host block: initials only (stage Match/Request), never name, photo or phone.
- Share and save (saved rooms list from E3.1).
- Report listing sheet: reason plus optional note, writes a `reports` document (targetType `listing`).
