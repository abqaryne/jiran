## Description

Rush hour changes which mode arrives on time. P1 adds a second column (peak and off-peak) to the commute card and a page with the step-by-step public transport route. Road modes use the openrouteservice time with a peak factor the team measures; transit modes use scheduled times; e-hailing at peak shows a range.

## Work needed

- Peak windows as config (assumption #2) and a measured peak factor for road modes.
- E-hailing surge as an assumed multiplier shown as a range, never as a live price.
- `getTransitRoute`: walk, board, alight, transfer and shuttle legs with stops, scheduled departures, total time and fare, from Prasarana GTFS plus the seeded UM shuttle.
- Public transport route page with the MapLibre map and the Peak / Off-peak toggle; loads only when opened (NFR1).
- The 'on time' check uses the student's actual departure time from their timetable.
