## Description

Show “Getting to [faculty]” for the candidate Listing: how to travel, one-way duration and an estimated fare per mode. A first-year needs no class schedule. Rent remains monthly and separate. [PRD Module 4](../../docs/product/PRD.md#module-4-apartment-to-faculty-commute-guide) supersedes the old monthly-cost design.

## Work needed

- One mode per row: estimated one-way time, fare or sourced range, and optional per-trip CO₂. Label “Estimated for leaving now” and the approximate origin.
- P0 basic transit instructions: walking links, service/line, boarding, alighting and transfers from supported data; include shuttle only if its schedule/route is available.
- Highlight the lowest known per-trip fare among applicable available modes; include walking. If the label excludes walking, state “Cheapest paid transport”. No before-class eligibility.
- E-hailing such as Grab is an estimate, not a live quote/booking; disclose fare source and pickup-wait inclusion. Missing fare/time has an explicit message, never zero by default.
- Remove true-monthly-cost headline, monthly commute rows and combined rent/utilities/commute breakdown. The full map/timeline remains E4.4 (P1); there is no Peak / Off-peak (removed 11 Nov 2026).
- The `CommuteSummary` parser and the fixture response are per-trip since 11 Nov 2026 (E3.3); the production wire format is still to be agreed with Aaron.
